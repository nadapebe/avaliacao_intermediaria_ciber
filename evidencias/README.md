# Evidências

Esta pasta guarda as evidências de execução exigidas pelo enunciado.

```
evidencias/
├─ ddg/      HAR, prints e JSONs exportados nas páginas do DuckDuckGo Privacy Test Pages
└─ sites/    HAR, prints e JSONs dos 3 sites reais analisados
```

Convenção de nomes:

- `<nome>_pagina.png` — print do resultado reportado pela própria página de teste
- `<nome>_plugin.png` — print do PrivacyLens em execução na mesma página
- `<nome>.json` — relatório exportado pelo PrivacyLens
- `<nome>.har` — tráfego exportado do DevTools do Firefox
- `<site>_blacklight.pdf` — relatório do Blacklight (The Markup)
- `<site>_ublock.png` — bloqueios reportados pelo uBlock Origin
