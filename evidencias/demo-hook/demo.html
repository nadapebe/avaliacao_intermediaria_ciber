Página de teste de hijacking / hook

Esta página local aciona, de propósito, os indícios que o PrivacyLens detecta. O script de terceira parte é carregado de 127.0.0.1.

Digite algo aqui (a página não guarda nem envia nada):

  1. Espere 45 segundos (o polling precisa de tempo para ser detectado).
  2. Clique no ícone do PrivacyLens e abra a aba Hijacking.
  3. Tire o print, exporte o JSON e salve o HAR.
