# PrivacyLens

Extensão para Firefox que detecta e apresenta ataques e violações de privacidade no cliente web.

Avaliação Intermediária de Cibersegurança — Insper.

## O que a ferramenta detecta

- Conexões a domínios de terceira parte
- Cookies injetados no carregamento da página (primeira/terceira parte, sessão/persistente)
- Armazenamento no cliente via HTML5 (localStorage, sessionStorage, IndexedDB)
- Sincronismo de cookies (cookie sync) e bounce tracking
- Canvas fingerprint
- Indícios de sequestro de navegador (hijacking e hook)
- Pontuação de privacidade a partir de metodologia explícita
